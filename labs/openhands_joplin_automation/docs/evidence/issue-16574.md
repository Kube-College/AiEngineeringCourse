# Joplin issue #16574 focus check

Captured: 24 September 2026. Source: [upstream issue #16574](https://github.com/laurent22/joplin/issues/16574). The reporter used Joplin 3.7.18 on Linux with the Markdown editor and said that creating a note or to-do left no typing cursor despite configuring title focus. The fixture excludes device identifiers, sync details, and the plugin list.

The controller-owned Electron check at `validation/desktop_16574.spec.ts` sets `newNoteFocus` and `newTodoFocus` to `title`. It clicks the corresponding creation button and types without clicking the editor. The assertion checks that the new title received the text.

The pinned fork checkout at `1d6beb0443e6d958b2c241f45978bd5de069f309` passed both checks on macOS and in the pinned Linux image `sha256:eb3a8f1b239ef7e2b4d6859bbc8a8f6c42fa981abc751a67f6af9670aa71e5af`. The Linux run used a disposable container with the profile's package build prerequisites and Xvfb. The focus failure was not reproduced. No `desktop-16574` validation profile is registered. A future implementation candidate needs a reproduced failing check before this scenario can serve as a regression gate.
